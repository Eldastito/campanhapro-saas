Gere uma apresentação 3D (galáxia + carrossel) trocando só os slides. Sobe imagens ou um PDF, ajusta e baixa.

Arraste imagens (PNG/JPG) ou um PDF aqui

ou clique para escolher arquivos

Como usar
  1. Sobe as imagens dos seus slides (na ordem) ou um PDF — cada página vira um slide.
  2. Reordene com ◀ ▶ e remova com ✕. Ajuste título e cores.
  3. Clique Baixar — sai um arquivo HTML único, que abre em qualquer navegador (offline).
  4. Na apresentação: clique avança · arraste gira (2 eixos) · pause volta ao carrossel · F tela cheia.
